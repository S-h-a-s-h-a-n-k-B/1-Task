Phishing Email Analysis Report – Task 2
Objective

To analyze a suspicious email and identify phishing indicators using basic security checks and header analysis tools.

Phishing Indicators Found
1. Suspicious Sender Address

The sender’s email address does not match the official domain, indicating possible email spoofing.

2. Header Analysis Issues

Using an online header analyzer:

The “From” and “Return-Path” fields do not match.

SPF, DKIM, or DMARC authentication failed.

Email originated from an unusual or untrusted IP address.

3. Malicious or Mismatched Links

The visible link text appears legitimate, but the actual URL (checked by hovering) redirects to a suspicious third-party website.

4. Suspicious Attachments

The email includes attachments commonly used for malware delivery (e.g., .html, .zip, .pdf).

5. Urgent or Fear-Based Language

The email tries to create urgency with phrases like:

“Your account will be suspended”

“Verify immediately”
This is a common social engineering tactic.

6. Grammar and Formatting Errors

The email contains spelling mistakes, odd sentence structure, and inconsistent formatting — signs of unprofessional phishing emails.

7. Request for Sensitive Information

The email asks the user to click a link or provide login credentials, which legitimate companies never request via email.

Conclusion

The email displays multiple strong phishing characteristics, including spoofed identity, mismatched URLs, header mismatches, suspicious attachments, and manipulation tactics.
The email is confirmed to be a phishing attempt.

Tools Used

Online Email Header Analyzer

Browser URL Inspection (hover method)

Key Learnings

How to identify phishing emails

Understanding spoofed domains and headers

Recognizing social engineering techniques

Importance of verifying links and sender authenticity
